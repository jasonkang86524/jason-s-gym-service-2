⚡ 雲端權限設定提示 (已啟用本地備援)

您的表單已完成提交並安全儲存於本地端！

系統偵測到您的 Firebase 專案 (gym-service-50960) 尚未開放 service_requests 集合的寫入權限 (Missing or insufficient permissions)。

若要讓資料正式寫入雲端 Firestore，請前往 Firebase Console → Firestore Database → 規則 (Rules)，貼上以下規則並點擊發布：

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /service_requests/{requestId} {
      allow create: if true;
      allow read, update, delete: if false;
    }
  }
}
